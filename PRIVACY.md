# Privacy Policy

**focus-music-youtube** is a personal automation project that generates ambient
focus/piano music videos and uploads them to a single YouTube channel on a
schedule.

## Data usage

- This app uses the YouTube Data API only to upload videos to the channel
  authorized by its owner during OAuth consent.
- It does not collect, store, or share any personal data belonging to third
  parties.
- OAuth credentials (client secret, refresh token) are stored as encrypted
  GitHub Actions secrets and are never committed to this repository or
  exposed publicly.
- No data obtained through the YouTube API is used for advertising, resold,
  or shared with any other party.
